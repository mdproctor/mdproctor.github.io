A preview of the form builder

by Kris Verlaenen - August 9, 2011
Process Tools Article
Whenever human actors participate in business processes (for example using the jbpm-console), forms can be used to show information to these users and/or ask for additional input. For example, the performance evaluation example that is included in the installer uses a simple form (as shown below) to ask the user to fill in some data related to his performance evaluation.


jBPM5 allows you to define these templates yourself for your user tasks (using HTML templates) so they can be used inside the console. We’ve however also been working on a form designer, a web-based application that allows business users (rather than developers only) to define these forms using a visual editor supporting drag-and-drop.

Mariano has made blog showing a cool demo of his progress so far.
