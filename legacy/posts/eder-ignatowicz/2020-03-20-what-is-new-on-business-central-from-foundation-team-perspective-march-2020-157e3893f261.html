What is new on Business Central, from Foundation Team perspective — March 2020

Recently, we pushed a lot of cool new features on Business Central added by Foundation Team. Those features are available soon at 7.34 release.

This post will do a quick overview of those. I hope you guys enjoy it!

Branch support on REST APIs

Users can leverage branch support on the REST API.

See more details on the full blog post.

Maven archetype support

Users can create projects based on templates.

See more details on the full blog post.

Create projects from empty repositories

Users can import an empty repository from a git provider service

See more details on the full blog post.

Squash Commits on a Change request

Users can choose to squash commits when merging a change request

See more details on the full blog post.

Other bug fixes and improvements:

We also fixed several bugs and improved Business Central on some specific scenarios:

  • JBPM-8826 — Forms — 10 Listeners get added each time a form is rendered
  • AF-2232 IllegalStateException displayed briefly in the UI when logging out from business-central
  • AF-2397 — Deletion of group from Business Central UI does not remove group from the security-policy.properties file
  • AF-2396 — Rest request to list spaces fails when RHPAM is integrated with RHSSO using SAML protocol
  • JBPM-8851 — Rename an asset change the quantity of assets returned by a search
  • AF-2424 Issue with the group permissions for the “Pages”
  • AF-2341 — Not able to restore files if the file uses a tag
  • AF-2395 -Unexpected error on Project level while launching test on cloned via REST project
  • AF-1395 — The new Form modeler editor is not locked when it is edited
  • AF-574 — [Layout editor] Components disappear after moving
  • AF-903 — [Settings] Made changes are no longer displayed after saving
  • AF-2404 — Package dropdown button is not visible (slowly appears) when creating an asset

Thank you to everyone involved!

I would like to thank everyone involved with this release, from the awesome Foundation Team Engineers, to the lifesavers QEs and all the UX people that help us make our work look awesome!
